# Мёртвый город

Выживание среди зомби в духе Project Zomboid для Android. Нативная игра на Kotlin, без HTML и WebView.

## Скачать
Готовый APK собирается автоматически после каждого изменения: **Releases → «Последняя сборка» → zomboid.apk**.

## Что есть
- Город из кварталов: дома с комнатами, магазины, полицейский участок
- Двери, окна (можно разбить), баррикады из досок (нужен молоток)
- Обыск мебели — лут генерируется при первом открытии
- Голод, жажда, выносливость, кровотечение, укусы
- Смена дня и ночи, ночью видно меньше
- Зомби слышат шум (бег, выстрелы, разбитые окна) и ломают двери
- Сохранение мира, смерть насовсем
- Игра на двоих по Wi‑Fi: один создаёт игру, второй вводит его IP

## Управление
Левая половина экрана — движение. Справа: Удар, Действие, Бег, Забить.
